# 中文改寫規則

ASD-STE100 是英文標準，沒有中文版。這個檔案把它的結構紀律對應到中文。字典類的詞彙規則不適用，改成「同一份文件裡，一件事只用一個詞」。讀者是 `agent` 時全部套用，讀者是人時套用結構規則，詞彙規則當建議。

## 適用範圍

- 輸入是中文就套用這個檔案。輸出用和輸入同一種字體。繁體輸入用台灣慣用詞：資料、程式、軟體、伺服器、網路、使用者、設定、預設。簡體輸入才用簡體。
- 程式碼、識別字、路徑、英文術語、錯誤訊息原樣保留。
- `scripts/ste-lint.py` 只檢查英文。中文改寫沒有機械檢查，靠下面的表逐句看。
- 字數以字元計，含標點。

## 結構規則，全部套用

| STE 規則 | 中文做法 | 改前 | 改後 |
|---|---|---|---|
| 主動語態 | 做事的人當主語。少用「被、由、受、遭」，除非做事的人真的不重要或不知道 | 檔案會被系統刪除 | 系統會刪除檔案 |
| 一句一件事 | 不用「並且、然後、再、同時、接著」把兩個指令接成一句 | 開啟檔案並讀取第三行，然後確認是否相符 | 開啟檔案。讀取第三行。確認第三行和設定值相符。 |
| 句長 | 指令一句 30 字以內，說明一句 40 字以內 | （一句 60 字的說明） | 拆成兩到三句 |
| 不用分號 | 「；」一律改成句號，分成兩句 | 先備份；再升級 | 先備份。再升級。 |
| 不省略主語 | 做事的人重要時，每句都要有主語。中文習慣省略，省了就有歧義 | 同步完成後會刪除暫存檔 | 同步完成後，系統會刪除暫存檔 |
| 名詞堆疊 | 「的」連用不超過兩個。超過就拆句 | 高壓燃油泵的入口閥的總成的安裝說明 | 入口閥總成的安裝說明。這個總成屬於高壓燃油泵。 |
| 不省略詞 | 不為了短而省掉受詞或條件 | 未備份會遺失 | 未備份的檔案會遺失 |
| 保留語氣 | 可能、也許、或許、大概、似乎、約、左右，原樣保留。不升級成肯定 | 請求可能已失敗 | 請求可能已失敗（不可改成「請求已失敗」） |
| 列表 | 三個以上的步驟或條件用編號列表，不用「、」串在一句裡 | 請確認網路、權限、磁碟空間和版本 | 請確認下列四項：1. 網路 2. 權限 3. 磁碟空間 4. 版本 |
| 段落 | 一段一個主題，六句以內 | | |

## 詞彙規則，方向而非硬性

| 規則 | 中文做法 | 改前 | 改後 |
|---|---|---|---|
| 一詞一義 | 同一件事全文用同一個詞。確認、檢查、驗證選一個。使用者、用戶、客戶選一個 | 先檢查設定，再驗證連線，最後確認結果 | 先檢查設定。再檢查連線。最後檢查結果。 |
| 動詞不名詞化 | 「進行、加以、做出、予以」加名詞，改回動詞 | 對日誌進行分析 | 分析日誌 |
| 行銷形容詞 | 無縫、強大、高效、極致、輕鬆、完美、智慧、一鍵。刪掉，或換成數字 | 高效的同步機制 | 每五秒同步一次 |
| 模糊動詞 | 處理、進行、執行、操作單獨出現時看不出做什麼。寫出實際動作 | 系統會處理錯誤 | 系統會記錄錯誤，然後重試一次 |

## 中文特有的歧義，改寫前先掃一遍

1. **主語省略**：「完成後會通知」是誰通知誰？補上主語和受詞。
2. **指代不明**：它、其、該、此、這個、前者、後者。換成名詞。
3. **「和、或」的範圍**：「刪除 A 和 B 或 C」有兩種讀法。拆句或加括號。
4. **否定的範圍**：「不都」和「都不」不同。「沒有全部完成」和「全部沒有完成」不同。寫成沒有歧義的那一種。
5. **「等」的開放列表**：「支援 PNG、JPG 等」到底支援哪些？寫完整，或明說「以及其他格式」。
6. **「應該」的兩種意思**：義務（你應該備份）和推測（應該已經完成）。義務改成「必須」或「請」。推測改成「可能」。只有上下文確定時才改，不確定就保留並在「保留原文：」裡說明。
7. **「可以」的兩種意思**：許可（可以刪除）和能力（可以開啟）。許可用「允許」或「可以」，能力用「能」。
8. **條件和時間的主體**：「一旦逾時就重試」是誰逾時、誰重試？「若 X，Y」兩邊都要有主語。
9. **數字和單位**：數字要有單位。「約、左右、以上、以下」是語氣詞，保留。「以上」包不包含本數，照原文，不確定就保留。

## 流程

和英文一樣。先讀懂整段，再逐句對表。每改一句都先檢查語氣詞有沒有被動到。改寫會失去必要的精確度（安全條件、範圍、數字）時，保留長句並說明。

## 輸出

- 預設只輸出改寫後的文字。刻意保留的長句，在文末加一行「保留原文：」說明保留了什麼、為什麼。
- 使用者要看規則表時，表頭用「違反的規則｜原文｜改寫」，表後一行寫「模式：Strict。N 處違規。」
