# Study modes

Five modes from the Feynman family (haunguyendev/feynman-skill). They are study tools, not explanations, and the source repo has no stars, so they stay out of `SKILL.md`. Read this file only when the user names one of them. Every rule in `SKILL.md` still holds: read the real thing first, keep hedges, define or avoid, answer in the user's language.

| Mode | The user says | Do |
|---|---|---|
| `map` | "What should I even ask about X?", "map X" | List 5 to 8 things worth understanding about the topic, each as a question, foundations first. No answers yet. |
| `analogies` | "Give me analogies for X" | Give 3 to 5 analogies. Say where each one breaks. Name the best one in a single memorable line. |
| `quiz` | "Quiz me on X", "test me" | Ask one question at a time. Wait for the answer. Raise the difficulty each round. Correct a wrong answer in two lines, then ask the next question. |
| `gaps` | "Here is my understanding, what am I missing", "check my explanation" | The user explains the topic. Find the exact point where their explanation goes vague or wrong. Name it. Ask one question that tests it. Then give the corrected version. |
| `break` | "Break this design", "what am I assuming" | For a design or decision. Name the hidden assumption it rests on and the edge case nobody tested. |

The reader setting from `SKILL.md` Step 2 still applies: a `quiz` for `kid` asks kid questions, a `break` for `peer` names the edge case in exact terms.
